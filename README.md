# 📋Smart To-do App 

 #### A clean and interactive task management application built with HTML, CSS, and Vanilla JavaScript.

The goal of this project was to practice core JavaScript concepts by building a fully functional web application without using any frontend frameworks or libraries. Throughout the development process, I focused on creating a responsive interface, improving user experience, and implementing interactive features using only native web technologies.

## ✨Overview

Smart Todo App allows users to create, manage, and organize their daily tasks in a simple and intuitive way. It provides real-time task tracking, visual progress updates, task filtering, and a modern Glassmorphism-inspired interface.

## 📌Features

- Create, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by All, Active, and Completed
- View live task statistics
- Dynamic progress bar with completion percentage
- Custom toast notifications
- Confetti animation after completing all tasks
- Empty state when no tasks are available
- Keyboard support (Press Enter to add tasks)
- Responsive layout for desktop and mobile devices

## 🛠️Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Font Awesome
- Canvas Confetti
